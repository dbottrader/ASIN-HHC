## Registry rules

1. Every artifact should receive a stable ID.
2. Every artifact should include origin date, source repo/file, hash, status, and evidence tier.
3. Symbolic artifacts must not be mixed with technical proof artifacts.
4. Prototype code must be labeled as prototype unless independently reproduced.
5. Witness packets must clearly separate templates from completed witness results.
