## Status

`LOOM / SYMBOLIC_GRAMMAR / NON_AUTHORITY`

This registry records the ANU-28 glyph language as symbolic operating grammar. It is valid as codex language, interface vocabulary, ritual-tech design grammar, and poetic structure. It is not presented as scientific proof.

## Interpretation boundary

Glyph meanings may be used for:

- visual systems
- UI states
- symbolic prompts
- codex chapters
- mythic navigation
- ritual-tech diagrams
- creative interpretation

Glyph meanings must not be used as:

- scientific measurements
- medical diagnostics
- financial signals
- legal conclusions
- proof of external causation
