## Rules

1. Each prototype must state whether it is static, simulated, or connected to live services.
2. No prototype may include secrets, private keys, API keys, or seed phrases.
3. Claims must be limited to what the demo actually does.
4. If a demo uses symbolic language, it must link back to the evidence boundary.
