## A. Existing repository code: ASIN handshake spiral

### A1. Point placement

**CODE-OBSERVED** — `ASIN-HHC/Index.html` and `ASIN-HHC/handshake.html`.

The inspected JavaScript implements a radial point sequence equivalent to:

```text
r_i = R * sqrt(i / N)
theta_i = i * alpha
x_i = cx + r_i * cos(theta_i)
y_i = cy + r_i * sin(theta_i)
```

where `alpha = phi_degrees * pi / 180` in the source code, `i` is the point index, `N` is the point count, and `R` is the maximum radius. The v0.2 implementation additionally multiplies angle by a user-controlled loveBias:

```text
theta_i = i * alpha * loveBias
```

This is a deterministic point-placement/rendering rule. With `r_i ∝ sqrt(i)`, points are distributed approximately uniformly by area over a disk under an irrational angular increment. The UI's default angle is 137.507764 degrees, a rounded golden angle.

**Important boundary:** the variable named `phi` in this UI is an angle in degrees, not the golden ratio constant φ. The UI also exposes a frequency parameter (432 Hz default), but in the inspected v0.2 code the frequency seeds a pseudo-random hue/color choice; it is not shown to drive a physical oscillator or a measured resonance process. No physical or therapeutic effect is established.

## F. Crop-circle morphology: measurable feature families

**DOC-OBSERVED as proposed analysis; no empirical results certified**

The accessible *Crop Circle Geometry Framework.docx* proposes measurable feature families:

- geometry: circle centers, radii, ring counts, axes, rotational/reflectional symmetry;

- recursive: radius progression, angular progression, circle-packing ratios, self-similarity score;

These are metric families, not one canonical equation. Every scalar needs a precise algorithm, input definition, units, preprocessing record, uncertainty, and control dataset before comparison claims are meaningful.

### F1. Box-counting dimension

**STANDARD-FORM reference**

```text
D_box = lim_(epsilon -> 0) [ log N(epsilon) / log(1/epsilon) ]
```

where (N(epsilon)) is the number of boxes of side (epsilon) needed to cover the selected set. A finite image yields an estimated slope over a stated scale range, not the exact mathematical limit.

### F2. Shannon entropy

**STANDARD-FORM reference**

```text
H(X) = -sum_i p_i * log2(p_i)
```

The probability distribution and binning must be specified (e.g., node occupancy, grayscale values, orientation histogram). Different choices measure different things.

### F3. Mutual information

**STANDARD-FORM reference**

```text
I(X;Y) = sum_(x,y) p(x,y) * log2( p(x,y) / (p(x)*p(y)) )
```

A proposed radial/angular mutual-information analysis must define the variables, discretization, sample size, and bias correction.

### F4. Graph Laplacian

**STANDARD-FORM reference**

```text
L = D - A
```

where (A) is the graph adjacency matrix and (D) is the diagonal degree matrix. Eigenvalues depend on the graph-construction rules; node/edge extraction must be reproducible.

### F5. Spectral / Fourier analysis

**STANDARD-FORM reference**

```text
X[k] = sum_(n=0..N-1) x[n] * exp(-i*2*pi*k*n/N)
```

A crop-circle image does not become evidence of encoded information merely because a transform yields spectral peaks. Sampling, rotation normalization, radial/angular parameterization, windowing, controls, and multiple-comparison correction are required.
