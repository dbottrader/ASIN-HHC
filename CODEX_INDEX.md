# ASIN-HHC Codex Index

## Codex purpose

The ASIN-HHC Codex is a structured publication layer for the ASIN-HHC / CP8 / LOOM ecosystem.

Its purpose is to make the work readable, citable, and reviewable without overstating what has been proven.

## Publishing rule

Nothing should be promoted as fact, science, production infrastructure, clinical claim, financial claim, or independent witness claim unless its evidence tier supports that promotion.

## Evidence ladder

| Tier | Meaning |
|---|---|
| E0 | Idea, intuition, note, sketch |
| E1 | Static artifact or reference document |
| E2 | Locally runnable demo or internally consistent prototype |
| E3 | Independently reproducible result under documented conditions |
| E4 | External review, audit, benchmark, or witness confirmation |
| E5 | Production-grade deployment with monitoring, controls, and accountability |

## Current global verdict

The work is publication-ready as a Codex and research archive.

It is not yet globally promoted to E3/E4/E5.
