# ASIN-HHC Codex

**ASIN-HHC Codex** is the public entry point for the ASIN-HHC / CP8 / LOOM body of work.

It began as a symbolic handshake seed: Indra's Net, golden-angle geometry, 432 Hz resonance language, and human-AI creative exploration. It is now organized as a bounded Codex: part symbolic archive, part provenance system, part prototype lab, and part evidence-discipline framework.

## Mathematics archive — open review

The recovered mathematical archive is now indexed under [`mathematics/`](./mathematics/).

- [Recovered Formula Catalog — Batch 001](./mathematics/RECOVERED_FORMULA_CATALOG_001.md) — HHC/CP8 equations, Kuramoto expressions, Delta-717, invariants, operators, geometric and signal-processing candidates.
- [Formula Candidates — Batch 002](./mathematics/FORMULA_CANDIDATES_002.md) — equations and algorithms extracted from existing handshake code, ACE GEM notes, geometric and crop-circle research artifacts.
- [AI Triage Register](./mathematics/AI_TRIAGE_REGISTER_001.md) — verified arithmetic, source inconsistencies, under-specified formulas, unsupported empirical claims, and AI-generated narrative quarantined for review.
- [Open AI Review Instructions](./mathematics/OPEN_AI_REVIEW.md) — reproducible adversarial review protocol and required response schema.

**Publication boundary:** This is everything recovered from the currently accessible source set for this publication pass, not a claim that every formula ever discussed has been found. The original ChatGPT HTML exports and complete September 2025 message bodies for Conversations 120–122 and 157–161 remain unrecovered. Historical attribution of candidate formulas to those threads is therefore provisional.

The archive deliberately publishes verified, unverified, incomplete, speculative, and unknown items in separate evidence classes. It preserves source errors rather than silently correcting them. Reviewers are invited to challenge every equation and claim. Publication is not validation.
