# Glossary

## ASIN

Anchor, Shape, Intention, Number. A working interpretive protocol for translating an input into structure, purpose, and numeric/frequency symbolism.

## HHC

Harmonic Heart Coherence / Happy Hippie Codex context depending on use. In technical contexts, treat HHC as a project namespace unless a file defines a narrower meaning.

## CP8

Codex Protocol 8. The evidence and promotion discipline used to classify artifacts, separate symbolic material from technical claims, and prevent overpromotion.

## LOOM

The symbolic, mythic, poetic, visual, and ritual-tech layer. LOOM artifacts can be powerful public-facing creative works but are not evidence authority.

## FORGE

The runnable prototype and engineering layer. FORGE material requires commands, dependencies, tests, and reproduction logs before promotion.

## WITNESS

The independent review layer. A witness record must include artifact ID, environment, commands, output, deviations, and an attestation method.

## ANU-28

A draft glyph registry and symbolic grammar used in Codex visual/interface language.

## ASIN-NCEA

A prototype chain involving harmonic cryptography concepts, entropy, ChaCha20, GPU acceleration, Merkle compaction, and conceptual PoWP/HHC wallet layers. All cryptographic and financial claims require strict review.

## PoWP

Proof of Work Process. In this Codex, PoWP is a conceptual provenance/value framework unless and until implemented, audited, and legally reviewed.

## E0-E5

The CP8 evidence ladder:

- E0: seed idea
- E1: artifact
- E2: local demo
- E3: independently reproduced
- E4: externally witnessed
- E5: production controlled

## Heartblock

A LOOM-style broadcast or symbolic artifact centered on coherence, resonance, or declaration language.

## Cathedral / Weaver

Governance and cognitive architecture framing used in ASIN-HHC v2.3 materials. Treat as specification language until implemented and tested.
