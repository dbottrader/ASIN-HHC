# Release Checklist

## v0.1.0 Codex Public

Before tagging the first public Codex release, complete this checklist.

## Repository hygiene

- [ ] No private keys, API keys, seed phrases, or secrets.
- [ ] README points to Codex index.
- [ ] Manifest is current.
- [ ] License choice is finalized or license-pending boundary is retained.
- [ ] Evidence boundary is visible from README.

## Artifact hygiene

- [ ] Every imported artifact has a registry entry.
- [ ] Every imported artifact has a hash.
- [ ] Symbolic artifacts are marked LOOM.
- [ ] Prototype artifacts are marked FORGE prototype.
- [ ] Technical claims include run instructions.

## CP8 hygiene

- [ ] No E3 claim without independent reproduction.
- [ ] No E4 claim without witness record.
- [ ] No E5 claim without production controls.
- [ ] Template witness packets are marked template-only.

## Publication hygiene

- [ ] Public announcement avoids overclaiming.
- [ ] Repository description is clear and bounded.
- [ ] Related repos are linked.
- [ ] Release notes explain what is included and what is pending.

## Final verdict phrase

`ASIN-HHC Codex v0.1.0 is a public symbolic, technical, and provenance archive with CP8 evidence boundaries. It is publication-ready as a Codex, not globally promoted as scientific proof, medical/legal/financial authority, or production infrastructure.`
