# Evidence Boundary

## Purpose

This document protects the ASIN-HHC Codex from overclaiming.

The Codex contains symbolic, poetic, technical, speculative, and prototype material. Those categories must remain separated.

## Core rule

A claim may only be promoted to the level supported by its evidence.

## Claim classes

### Symbolic claims

Examples:

- glyph readings
- crop-circle interpretations
- resonance language
- mythic framing
- ritual-tech visual systems

Allowed status: `LOOM / SYMBOLIC_ORIENTATION / NON_AUTHORITY`

These are valid as art, interpretation, spiritual-poetic language, or design grammar. They are not scientific proof.

### Technical claims

Examples:

- code runs locally
- hashes match
- tests pass
- an invariant is enforced
- a harness reproduces a result

Allowed status depends on evidence tier.

Technical claims require source files, deterministic procedures, test logs, and reproducible verification.

### Scientific claims

Examples:

- external physical causation
- crop-circle origin conclusions
- quantum/biological/medical assertions
- measured universal principles

Scientific claims require independent reproducibility, empirical data, methods, and review. Until then, they remain interpretive or speculative.

### Medical, legal, and financial claims

The Codex must not present itself as medical, legal, or financial authority.

Any such material must be framed as personal context, research notes, or non-professional drafting support unless reviewed by a qualified professional.

## CP8 evidence ladder

| Tier | Label | Minimum requirement |
|---|---|---|
| E0 | Seed | idea, intuition, sketch, note |
| E1 | Artifact | static file, document, image, prompt, page |
| E2 | Local demo | runnable locally by creator or assistant |
| E3 | Reproducible | independently reproduced from instructions |
| E4 | Witnessed | external reviewer/auditor confirms result |
| E5 | Production | deployed with controls, monitoring, accountability |

## Promotion rule

No artifact should be promoted higher than its weakest unsupported dependency.

## Current global Codex boundary

The Codex is publication-ready as a structured archive and research scaffold.

It is not globally promoted as production engineering, scientific proof, autonomous AI doctrine, or audited infrastructure.
