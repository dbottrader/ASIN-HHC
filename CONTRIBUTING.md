# Contributing

## Contribution rule

Every contribution must preserve provenance and evidence boundaries.

## Required metadata

When adding an artifact, include:

- artifact title
- creator/source
- date created or recovered
- source repository or upload source
- hash if available
- evidence tier
- claim boundary

## Claim labels

Use one of these labels:

- `LOOM_SYMBOLIC`
- `CODEX_REFERENCE`
- `CP8_EVIDENCE_SCAFFOLD`
- `FORGE_PROTOTYPE`
- `WITNESS_PENDING`
- `WITNESS_CONFIRMED`

## Do not add

- private keys
- seed phrases
- medical claims presented as treatment advice
- financial claims presented as investment advice
- scientific claims without reproducible evidence
- AI-generated success logs without runnable proof

## Preferred file style

- Markdown for documents.
- JSON for manifests.
- HTML demos should be standalone when possible.
- Each prototype should include a README and run instructions.
